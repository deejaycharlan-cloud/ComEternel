# Utiliser E5

1. Ouvrez **Projets**, créez ou ouvrez un projet, puis choisissez **Traiter la demande et préparer les tâches**.
2. Vérifiez objectif, public, message, ressources et date utile. Enregistrez une décision motivée. Une demande acceptée permet de préparer le travail.
3. Choisissez une occurrence (ou la campagne), un pack et le traitement des dates passées. Cliquez **Prévisualiser**, puis **Continuer**.
4. Dans l’aperçu, retirez les étapes inutiles, adaptez les dates et les livrables, consultez les disponibilités et choisissez les personnes. La vidéo reste facultative. Appliquez le pack après vérification.
5. Chaque destinataire retrouve ses propositions dans **Mes tâches** et peut accepter ou refuser. Les propositions ne sont pas des engagements.
6. Ouvrez une tâche pour suivre son avancement. Une personne autorisée peut revoir les consignes, la date, la priorité, les préalables et proposer un remplacement. Le remplaçant accepte à son tour.
7. Déclarez vos disponibilités dans **Mes tâches**. Pour les collègues, l’absence de déclaration signifie disponibilité inconnue.
8. En cas de changement de date, revoyez chaque échéance signalée. Un projet annulé ou une demande reportée conserve les tâches et suspend leur avancement.

Une tâche terminée reste distincte d’un contenu validé ou publié. Les liens utiles peuvent être inscrits dans les consignes ; la connexion des fichiers arrive avec E6.

## Essai sans toucher à vos données

Un espace fictif séparé est disponible sur `http://localhost:3101`. La session de recette est ouverte dans le navigateur intégré. Le projet « RECETTE — rencontre de bénévoles » contient une tâche terminée et une tâche à attribuer ; vous pouvez proposer cette seconde mission à « Recette E5 », puis l’accepter dans Mes tâches. Vous pouvez aussi créer un nouveau projet pour essayer un pack depuis le début. Les dates de 2090 sont volontairement fictives.

Votre application habituelle reste sur `http://127.0.0.1:3100`, avec ses espaces conservés.
